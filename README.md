# Retail Sales Performance Analysis & Customer Trend Visualization

## Overview
This project focuses on analyzing retail sales performance and customer purchasing trends using Business Analytics concepts. The objective is to transform raw sales data into meaningful business insights through data cleaning, exploratory data analysis (EDA), SQL querying, and interactive visualizations.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- SQL
- Excel
- Power BI / Tableau

## Features
- Monthly Sales Trend Analysis
- Quarterly Revenue Analysis
- Product Category Distribution
- Unit Price Distribution Analysis
- Data Cleaning & Transformation
